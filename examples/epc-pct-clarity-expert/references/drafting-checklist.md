# Pre-Filing Drafting Checklist — Clarity-Proofing the Claims

A practical audit that catches the majority of Art. 84 EPC / Art. 6 PCT objections **before** the application is filed. Each item maps to the corresponding **EPO Guidelines F-IV** section and the leading case law.

> Use this list as a final pass after the claims are otherwise complete. Score each item: ✅ pass / ⚠️ amend / ❌ rewrite.

## I — Category-Specific Audits

### I.1 — Apparatus / device claims
- [ ] All structural components named
- [ ] All functional couplings stated
- [ ] No "for" use limitation hidden as a structural feature

### I.2 — Method / process claims
- [ ] All necessary steps included
- [ ] Step order specified where relevant
- [ ] Conditions (temperature, pressure, time) within useful ranges

### I.3 — Composition / formulation claims
- [ ] All essential components listed with proportions
- [ ] "Comprising" vs "consisting of" deliberate
- [ ] Component identity precise (CAS number, structural formula, or unambiguous name)

### I.4 — Second medical use (Art. 54(5))
- [ ] EPC 2000 form ("X for use in treatment of Y")
- [ ] Therapeutic indication specific (not "treatment of disease")
- [ ] Dosage / regimen if necessary for novelty

### I.5 — Computer-implemented invention
- [ ] Technical effect clearly stated
- [ ] Category clean (method / apparatus / program product)
- [ ] No pure business method / mathematical method without technical embodiment

## J — Cross-Statutory Sanity Checks

| # | Check | Why |
|---|---|---|
| J1 | Claims still **novel** over closest prior art after the clarity audit (terms tightened may inadvertently match prior art) | Art. 54 |
| J2 | Claims still **inventive** after tightening | Art. 56 |
| J3 | Description still **sufficient** for the (possibly amended) claim scope | Art. 83 |
| J4 | No **added matter** risks if any changes were made post-filing (text in priority document vs current draft) | Art. 123(2) |
| J5 | Translations consistent across language versions if filed in multiple languages | Rule 7 EPC, Art. 14 EPC |

## K — Priority Document Discipline (avoiding Art. 123(2) trap later)

When drafting the priority application, **for every feature you might want to claim later**:
1. Disclose it in the **description** AND in a **claim**
2. Disclose it both in **specific** examples and in **generalised** wording
3. Disclose **combinations** explicitly (don't rely on hindsight combination)
4. Disclose **ranges** with intermediate values to support later narrowing

This prevents the most painful late-prosecution problem: needing to amend for clarity but the basis is lacking in the application as filed.

→ Cross-ref: [related-provisions.md § Art. 123(2)](related-provisions.md#article-1232-epc--added-matter)

## L — PCT-Specific Pre-Filing

If filing PCT → EP:
- [ ] Apply EPC standards from the start (the EPO is the strictest ISA)
- [ ] Avoid late-PCT amendments (Art. 19 PCT) that introduce clarity issues
- [ ] Choose ISA carefully — EPO is highest quality but most rigorous
- [ ] Anticipate EP regional phase Art. 84 review even if ISA opinion was favourable
